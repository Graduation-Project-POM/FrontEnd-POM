# Palestine Mathematics Olympiad (PMO) Platform

A modern and user-friendly digital platform designed to organize and present all information related to the Palestine Mathematics Olympiad in one place.  
The platform serves students (ages 15–18), teachers, schools, and anyone interested in problem-solving and mathematical competitions.

---

## 🎯 Project Goals

- Provide a clear and structured overview of the Olympiad.
- Centralize scattered information (structure, goals, partners, success stories).
- Offer a smooth and modern user experience following UI/UX best practices.
- Encourage more students to participate in PMO through an accessible digital platform.

## ⚙️ Implementation Overview

### **Backend**
- RESTful APIs built with ASP.NET Core.
- EF Core used for database mapping and CRUD operations.
- Redis caching implemented to improve performance and minimize repetitive SQL queries.

### **Frontend**
- Built using React.js with a component-based architecture.
- Material UI used to ensure consistent and responsive styling.
- TypeScript improves code readability and prevents runtime errors.

### **Database**
- SQL Server stores platform content, participant info, partner data, events, and more.
